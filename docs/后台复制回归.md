# 0.2.3 后台复制回归

开启“截图OCR → 设置 → 识图后的操作 → 复制结果”后，截图识别和托盘剪贴板识别在后台完成。非空文本自动写入剪贴板，结果与截图历史保留，用户从托盘打开主窗后可查看。关闭复制选项后显示识别界面。二维码继续显示扫描结果。

## 修复原因与实现

0.2.2 的复制开关只控制结果复制。首次隐藏启动后收到截图会进入图形界面，已经创建过主窗时，事件桥接还会显示原生窗口，随后截图处理再次发出显示与聚焦命令。因此只删除一处显示命令会留下闪窗或隐藏窗口不处理结果的问题。

0.2.3 在首次隐藏启动时直接使用后台工作线程完成识别、复制和历史保存。明确打开主窗后继续复用同一工作线程与模型会话。打开过主窗再隐藏时，由事件循环处理隐藏窗口的到期更新，无需显示窗口；没有待处理更新时继续等待消息。成功的静默截图跳过临时主窗恢复，取消或截图失败仍恢复此前窗口状态。非空结果由原生剪贴板接口写入，失败时保留结果和中文错误。
